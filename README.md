# Life RPG

把现实生活变成一场 RPG。你不是在完成 Todo，而是在培养自己的角色。

iOS 原生应用，SwiftUI + SwiftData，纯本地运行，无需联网、无需账号。中英双语，竖屏 iPhone，iOS 17+。

## 快速开始（macOS）

```bash
brew install xcodegen
xcodegen generate
open LifeRPG.xcodeproj
```

要求 Xcode 15+ / iOS 17+。仓库不提交 `.xcodeproj`，它由 `project.yml` 生成。

## 产品定位

打开应用看到的是一场正在进行的冒险，而不是一张无穷的待办清单。任务被收进冒险者工会的告示栏；完成它们会涨经验、涨金币、升级技能与核心属性。

核心习惯是 **Tomorrow Planning**：前一天规划的任务次日自动成为主线并获得 +20% 奖励；当天临时新增的任务是支线，奖励 -20%。这个差距是刻意的，它把玩家推向「提前规划」。

## 核心机制

- **主线 / 支线**：由「计划日」与「创建日」的关系自动派生，不需要手动切换类型。周期任务按模板生成，视同提前规划的主线。
- **奖励引擎**：难度、时长、优先级、准时度、连续天数共同决定最终 EXP 与 Gold。同组加成互斥，全部数值由配置表驱动。延期完成现在是 **-50%**。
- **失败结算**：单次任务逾期超过 3 个活跃日后取消，写入失败历史。周期任务按 7 个活跃日窗口结算配额，欠债可再宽限一周，仍未达成则失败。
- **技能栏位**：开局 5 个栏位。完成任务时把经验按权重分给关联技能；技能独立升级到 Lv100，并按亲和度喂养核心属性。
- **五个核心属性**：身体力、认知力、生活力、社交力、创造力。描述「你正在成为怎样的人」，技能描述「你学会了什么」。
- **幸运**：无法主动训练。极低概率自然成长，偶尔触发幸运日（小吉 / 中吉 / 大吉 / 天命），当天经验与金币额外加成。
- **习惯与连续**：一键打卡，达成当日目标才发奖励。登录连续 7 / 30 / 100 天带来全局 ×1.1 / ×1.2 / ×1.5。漏登一天可用商店的**法术护盾**保住连胜。
- **请假卡**：购买后选一天冻结进度。暂停日不计入周期窗口，周期不会因此提前失败。
- **成就 / 称号 / 挑战**：三者共用同一套规则引擎。新增内容只需要改 JSON。
- **经济走流水账**：任何 EXP / Gold 变动都先落一条 `RewardTransaction`，撤销时按流水反向回滚，而不是重算公式。
- **商店以装饰为主**：主题氛围、头像框、背景、特效、音效、宠物不改数值。道具页的请假卡 / 保险卡是明确的功能例外，只改日程时钟或连胜保护。

## 界面结构

底部四个 Tab。首次启动走「冒险者登记」，紧接着强制新手引导（发布主线、支线、建一条习惯），之后进入主界面。升级、解锁、幸运成长会从顶部弹出庆祝横幅；任务逾期失败、法术护盾生效会弹出系统提示。

```
首次启动 → 冒险者登记（称号 + 头像 → 初始技能）
         → 新手引导（主线 → 支线 → 习惯）
         ↓
┌────────┬────────┬────────┬────────┐
│  今日  │  成长  │  统计  │  我的  │
└────────┴────────┴────────┴────────┘
```

配色与氛围来自商店主题（默认「起始之地」：浅蓝雾气与金线边框）。可在设置里切换浅色 / 深色 / 跟随系统，以及是否启用 RPG 风格界面。主题不只改强调色，还会在页面背后叠林雾、余烬、星点、花瓣或金辉。

完成任务时行内跳出 EXP / 金币数字，并有默认触感反馈。装备「完成火花」「升级光爆」「经典音效包」后会再叠全屏粒子与提示音。首页右下角可出现跟随的宠物。

---

### 冒险者登记（Onboarding）

两步向导，不可跳过昵称：

1. **称号**：给角色起名（最多 16 字），并选头像——预设 SF Symbol，或从相册 / 相机导入照片。点头像之后仍可更换。
2. **技能**：从预设目录挑 0–5 个方向，也可以自定义。一个都不选也可以，栏位留到以后再学。

完成后进入强制新手引导。注销账户会清空存档并回到登记。

---

### 新手引导

登记结束后，遮罩高亮真实按钮，按顺序走完第一天该会的操作：

1. 欢迎 → 点告示栏加号，发布一张**单次主线**
2. 再发一张当天的**支线**（只需标题）
3. 切到底部「成长」→「习惯」，创建第一条日常修行

步骤写进设置。杀进程后从最近的入口步恢复，避免卡在已经关掉的 sheet 里。填表步骤不会挡住输入框。

---

### 今日（Home）

标题「今日冒险」。只展示今天，打开应用立刻能动手。

| 区域 | 内容 |
| --- | --- |
| 角色卡 | 头像（含商店边框）、昵称、佩戴称号、金币、连续登录火焰、等级与 EXP 进度、下一档连续加成提示 |
| 幸运日横幅 | 当天抽到幸运时出现，显示档位与经验/金币加成 |
| 冒险者工会 | 金边告示板：完成进度、主线/支线/习惯计数、今日已获 EXP 与金币；分段筛选全部 / 主线 / 支线 |
| 日常修炼 | 今日习惯打卡列表，点一下就完成 |
| 宠物 | 若已装备，蹲在右下角轻轻弹跳或打盹 |

逾期任务不再单独成区，而是混在告示栏里，行上打红色「已延期」标记，长按可挪到今天或删除。已完成沉底，未完成按优先级排列。

导航栏左侧打开 **告示日历**（查看任意一天会出现什么委托），右侧打开 **发布任务** 向导。下拉刷新会重新跑每日结算。

---

### 发布任务向导（工会接待处）

用问答把一次发布拆成几步，选错会影响报酬：

1. **张贴什么**：主线（计划委托，安排在未来，+20%）或支线（临时委托，今天开始今天截止，-20%）。
2. **主线形态**：单次任务（指定开始日与当天截止时间）或长期委托。
3. **长期怎么排**：周期重复（每天 / 每 N 天 / 每周指定 / 每周若干次 / 每月），或一段时间（一条跨越多日的委托）。
4. **委托细节**：名称、描述、难度、优先级、预计时长、技能经验分配、排期与截止时间。底部实时显示预计报酬。

难度五档：轻松 / 简单 / 普通 / 困难 / 史诗。优先级五档：最低 → 最高。技能经验所有技能共用 100%。

周期任务按 7 个活跃日窗口冲配额；窗口没完成会进入延期补债周，仍未达成则失败并移出任务栏。

---

### 成长（Growth）

分段三个视角：

**属性**

- 五个核心属性卡片：图标、中英名称、有效等级（训练等级 + 升级加点）、简介、经验条。
- 点进详情：定义、涵盖领域、成长效果（匹配该属性的技能经验加快）、正在喂养它的技能列表。
- 底部独立一张 **幸运** 卡：不能训练，只能被惊喜点亮；展示今日命运。

**技能**

- 顶部显示栏位占用（例如 `3 / 5`）。栏位满了之后只能通过升级选额外栏位，或忘记一个技能腾位置。
- 按主属性分组。每行显示等级、经验条、关联任务奖励加成。
- 可从预设目录学习或完全自定义（名称、图标、颜色、属性亲和）。忘记技能会清空等级与经验，不可撤销。

**习惯**

- 列表展示每日目标、连续天数、最近 30 天。
- 编辑：名称、图标颜色、每日目标次数、每天提醒。奖励只在达成当日目标的那一次发放，把目标拆细不会拿到更多经验。
- 首页与成长页都可以打卡、撤销一次、补满今天。

---

### 统计（Statistics）

范围切换：日 / 周 / 月 / 年 / 全部。

- **概览**：完成率、完成任务、习惯打卡、获得 EXP / Gold、活跃天数；可选平均周转小时。
- **每日获得**：柱状图，经验产出节奏。
- **主线与支线**：比例条 + 文案提示（健康规划 / 各占一半 / 几乎全是临时任务）。
- **技能成长曲线**：按技能筛选的等级走势。
- **完成热力图**：最近 26 周，GitHub 风格，周一到周日自上而下，颜色跟随当前主题。

---

### 我的（Profile）

分段三个视角，右上角齿轮进设置。

**总览**

- 同一张角色卡。
- 五个核心属性的紧凑行，点进详情。
- 终身数据网格：累计天数、当前 / 最长连续、完成任务、主线 / 支线、习惯打卡、完美达成、累计 EXP / Gold。
- **失败历史**：逾期过久被取消的任务快照（标题、计划区间、进度、失败日）。

**荣誉**

- 成就、称号、挑战各展示最多 5 条预览（已解锁 + 接近完成），再点「查看全部」。
- 称号可直接在预览里佩戴。
- 底部入口进入奖励流水。

**商店**

嵌在「我的」里的完整商店，横向胶囊切换分类。

### 商店

分类：主题、头像框、背景、特效、音效、宠物、道具。商品有等级门槛与金币价格。装饰品已拥有可装备 / 卸下。右上角显示当前金币。

| 分类 | 作用 |
| --- | --- |
| 主题 | 强调色 + 页面氛围（林雾、余烬、星轨、落樱、金辉） |
| 头像框 | 青铜 / 白银 / 黄金 / 秘境光环 |
| 背景 | 羊皮卷纸纹、极光，与主题叠加 |
| 特效 | 完成火花、升级光爆（叠在默认反馈之上） |
| 音效 | 经典音效包：完成、升级、购买、打卡 |
| 宠物 | 史莱姆、学者猫头鹰，出现在首页角落 |
| 道具 | **完美防御力场**（请假卡，250 G）选一天冻结进度；**法术护盾**（保险卡，400 G）漏登一天自动保住登录连胜，持有上限一张 |

主题与背景叠在系统分组底色上，不强制深色皮肤，避免把暗黑模式打穿。

### 设置

从「我的 · 总览」右上角进入。

| 分组 | 内容 |
| --- | --- |
| 语言 | 跟随系统 / 中文 / English。切换后界面立即更新；自己起的任务、技能、习惯名称不会被翻译 |
| 外观 | 浅色 / 深色 / 跟随系统；RPG 风格界面开关；配色主题入口（跳转商店） |
| 时间 | 一天从几点开始（0:00–8:00，默认 4:00）；未完成任务是否自动顺延 |
| 通知 | 总开关、请求系统权限。只会在三种情况提醒：18 小时没打开 App、超过 1 天没使用、任务截止前 1 小时 |
| 数据 | 导出完整备份 JSON（含失败历史）、任务 CSV、每日统计 CSV、成长报告 PDF；从备份恢复 |
| 测试 | 解除商店限制并无限金币（不扣真实余额，关闭后立即恢复） |
| 账户 | 注销并清空存档，重新进入初始化 |

一天起始时刻会改变「今天」的口径：设为凌晨 4 点时，凌晨 1 点完成的任务仍算作前一天。中途修改可能让连续记录看起来发生跳变。

### 升级选择

玩家升级时金币先入账，再弹出不可关闭的选择页，二选一：

- **分配 1 点属性点**：立刻加到五个核心属性之一，匹配技能的经验会涨得更快。
- **解锁 1 个技能栏位**：上限 +1，可立刻学习新技能，也可以把栏位留空。

技能升级、属性升级、幸运成长、成就解锁走顶部庆祝横幅，不打断当前操作。

## 奖励公式（摘要）

```
baseEXP    = difficultyBaseEXP[difficulty] * durationFactor(estimatedMinutes)
baseGold   = baseEXP * goldRatio
multiplier = clamp(1 + Σ(每个分组内取一条生效的加成), 0.2, 3.0)
finalEXP   = round(baseEXP * multiplier * streakMultiplier)
finalGold  = round(baseGold * multiplier * streakMultiplier)
skillEXP   = round(finalEXP * link.expShare)
```

加成分组（同组互斥，惩罚优先）：

| 分组 | 命中 | 效果 |
| --- | --- | --- |
| 规划 | 提前规划 / 当天临时 | +20% / -20% |
| 准时 | 按时完成 / 延期完成 | +20% / -50% |
| 优先级 | 五星任务 | +30% |
| 连续 | 连续完成 | +10% |

最优约 **2.7 倍**，最差约 **0.3 倍**。规划任务与临时任务仍有差距，用来驱动 Tomorrow Planning。周期任务进入延期补债周后，即使当天完成也按延期结算。详细推导见 [奖励与平衡](docs/03-reward-balance.md)。

## 时间与每日结算

唯一时间源是 `GameCalendar`，业务代码禁止直接用 `Date()` 判断「今天」。启动或回到前台时跑每日结算，可补算（几天没开 App）且幂等（同一天不重复）：

1. 封存前一日的 `DailyRecord`
2. 可选：把未完成的单次任务顺延到今天（仍标延期）
3. 结算周期窗口（达成则开新窗口，否则进入宽限；宽限仍失败则写入失败历史并取消待办）
4. 为今天生成周期实例（暂停日不生成）
5. 逾期超过 3 个活跃日的单次任务失败
6. 若持有法术护盾且漏登恰好一天，自动保住登录连胜
7. 推进登录连续，并把早已中断的习惯 / 周期连续清零
8. 跑解锁引擎

补算上限 400 天。暂停日不计入活跃天数，请假不会把「下周三才到期」提前推成失败。详见 [状态流](docs/04-state-flow.md)。

## 架构

```
Features (SwiftUI View)
   ↓ 只读 @Observable
Stores (@Observable，界面状态 + 用例编排)
   ↓
Services (有状态，持有 ModelContext，负责事务与副作用)
   ↓
Engines (纯函数，只吃值类型，零依赖，可单测)
   ↓
Models (@Model SwiftData 实体) + Core (GameCalendar / GameConfig)
```

- `Engines/` 不得 `import SwiftData`，因此可以在没有模拟器的情况下跑单测验证数值平衡。
- 数值不写在代码里，全部来自 `Resources/Config/*.json`，启动时由 `GameConfig` 加载。
- 没有全局单例。`AppContainer` 在启动时构造，通过 `.environment()` 注入。

目录对应：`Sources/App` 入口与根导航 · `Sources/Features` 各页面 · `Sources/Stores` · `Sources/Services` · `Sources/Engines` · `Sources/Models` · `Sources/Core` · `Resources/Config` · `Tests/EngineTests`。
